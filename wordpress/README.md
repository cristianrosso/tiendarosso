# WordPress — P2

Este directorio reserva la futura implementación WordPress.

P2 deberá crear:

- `wp-content/themes/tiendarosso/`: tema de bloques, `theme.json`, templates, template parts y patrones.
- `wp-content/plugins/tiendarosso-commerce/`: formularios, oportunidades, analítica y futuras integraciones comerciales.

El prototipo de `prototype/` no se considera editable en Gutenberg y no debe presentarse como tal hasta completar y probar P2.
